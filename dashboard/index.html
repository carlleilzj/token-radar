How the radar scores a protocol

One function scores every row. Nothing is hand-picked and no protocol name is special-cased.

implied value = TVL × category multiple × growth × maturity × chains
  category multiple = median mcap/TVL of the category's protocols
                        whose token already trades (≥3 of them,
                        else the global median), clamped to 0.05–0.80
  growth            = 1 + clamp(7d change, −60%, +120%) / 100 × 0.5
  maturity          = 0.6 + min(age in days, 1095) / 1095 × 0.4
  chains            = 1 + 0.02 × min(chains − 1, 5)

What the board never ranks

    Centralised exchanges, bridges, liquid-staking and restaking products, versioned pools and exchange products cannot be farmed for a launch of their own, so they are set aside and counted here instead of ranked.

    Read it honestly

    The snapshot is DefiLlama's record, not proof: a protocol on this board records no token, which is not the same as having none. An implied value is this entry's own claim about what a token would be worth if the protocol's record stayed as it is. It does not predict whether or when a token is issued.
